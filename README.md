# Artist Portfolio Website

A responsive, single-page artist portfolio built with **React and Vite**. This
project showcases an artist's work through a colorful, visually driven layout
designed to highlight artwork, commission options, testimonials, and contact
information.

## Overview

The website features a modern portfolio design with a warm color palette, bold
typography, and an image-focused layout. It brings together an artist
introduction, artwork gallery, commission pricing, client testimonials, and
contact information in one cohesive experience.

## Features

- **Hero Section:** Artist introduction with featured artwork and navigation.
- **About Section:** Introduction to the artist and their creative practice.
- **Artwork Gallery:** Image gallery showcasing a variety of artwork.
- **Commission Options:** Pricing cards for portrait, half-body, and full-body
  commissions.
- **Testimonials:** Client reviews and artwork highlights.
- **Contact Section:** Space for artist contact information and inquiries.
- **Social Links:** Footer navigation and social media links.
- **Responsive Layout:** Designed to present the portfolio across different
  screen sizes.

## Built With

- React
- Vite
- JavaScript
- HTML
- CSS

[View the live website](https://natewarddev.github.io/simple-artist-portfolio-project/)

## Purpose

This project was created to practice building a single-page portfolio with
React, focusing on visual presentation, component-based development, and
responsive web design.
